# 金山地瓜地方誌 v4 建置來源

此資料夾是 2026 年重製版網站的正式來源。修改網站時，請先修改這裡的版型、內文、樣式、腳本或圖片，再重新建置。

- `build_yam.py`：建立共用頁首、側欄、頁尾與 v4 首頁。
- `templates/home.html`：首頁文案、主視覺、探索路線、搜尋及吉祥物；`{{ cards }}` 由單元表產生。
- `content/<單元>/<頁碼>.html`：31 篇正式內文，已包含潤飾與結構修正；重建會保留這些內容。
- `site.css`：單一 v4 樣式，依基礎樣式、響應式、列印整理。
- `site.js`：主題篩選、章節搜尋、手機選單、閱讀目錄（貼頂跳段落選單）、字級偏好、閱讀進度、照片燈箱（可翻頁）、頁首縮小、捲動顯示等動態效果。
- 閱讀體驗：同單元的小節讀到篇尾便自動往下接續，不分長短篇；已載入的小節可向上回看，並保留段落選單與接續閱讀。
- `img/*.webp`：網站實際使用的主視覺與透明吉祥物。
- `icons/*.svg`：自繪的章節總覽、地圖、料理鍋、筆記本圖示；對應圖示內嵌於首頁，以減少請求。
- `README_site.md`：重建時複製到網站的維護文件。
- `copy_edits/`：保留歷史文案潤飾紀錄；新版以 `content/` 為準，無須重套。

需要 Python 3 與 `lxml`。從儲存庫根目錄執行：

```sh
python3 src/build_yam.py 2015-original /tmp/yam-preview
```

第三個參數可指定自訂樣式、腳本與圖片的來源資料夾；省略時使用本資料夾。
請先檢查獨立輸出目錄。建置會替換指定輸出目錄，且會拒絕將來源目錄或其父層指定為輸出。

日常修改請改此資料夾的版型、內文、樣式、腳本或圖片，再重建。直接修改部署檔案不會自動回寫來源。

圖片：`jinshan-harvest-1000.webp` 約 229 KB；`jinshan-harvest-600.webp` 約 100 KB。首頁主視覺使用 `srcset` 提供不同尺寸的圖片，故事卡使用 600px。新吉祥物以美工組原作為基礎進行 AI 重繪，原作 `6.png` 及歷史人物照片保留。大型 PNG 與舊 JPG 原稿封存於 `../yam51103_v4修正前_20261025/artwork/`。

驗證正式來源與部署版本一致（包含 32 頁完整 HTML、內文、樣式、圖片與本機錨點）：

```sh
python3 src/verify_build.py
```

此驗證會建立獨立暫存輸出，不會替換部署網站。互動功能仍需另以瀏覽器實測。

連續閱讀：同一單元的小節會在接近篇尾時自動接在下方，長短篇皆適用；只有讀完單元最後一小節，頁尾才顯示「探索下一章」。`build_yam.py` 的 `reading_info()` 仍以非空白字數不超過 1000、照片不超過 6 張標記短篇，供預先接上相鄰短篇及閱讀位置功能判斷使用；長篇會按閱讀需要載入。`site.js` 透過 HTTP 載入下一小節，匯入 ID 會加上前綴，圖片與連結則依來源位置解析；不攔截滑鼠滾輪或觸控捲動。讀者可切回單篇，選擇記在目前分頁的 `sessionStorage`。閱讀列的「單篇」可開啟目前小節的獨立網址，方便分享；匯入小節的錨點也可在重新整理後恢復。暫時載入失敗時提供重試與直接開啟連結；直接開啟本機 HTML 或停用 JavaScript 時，保留原有頁間連結。

長篇閱讀：底部閱讀列提供目前篇名、閱讀百分比、上一篇／下一篇與段落選單。閱讀位置依目前小節的獨立網址、標題順序及段落內比例記在 `sessionStorage`，重新開啟同篇時由讀者點選「接續上次閱讀」，不蓋過網址指定的錨點；恢復前會先載入前方照片以穩定位置。保留字級調整、照片放大及人物分工篩選；段落選單支援 Escape 關閉與鍵盤操作，尊重減少動態效果的系統設定。


章節卡片：`CHAPTER_COVERS` 定義封面色與文字；`COMPANIONS` 定義紫、紅、黃藷的八個角色。`img/chapter-companions.webp` 是依網站原有吉祥物風格重繪的透明插畫圖集，四欄兩列；`chapter_drawing()` 產生對應 CSS 圖集位置。首頁八張卡片共用一張圖片，保留圓潤比例、深色手繪線條、暖色顆粒與綠色圍裙。原稿與被取代的 SVG 封存於 `../yam51103_卡片插畫統一前_20261025/`。

內頁：`page_shell()` 使用各章相同的主題色與角色，產生側欄封面、麵包屑與下一章入口；文章封面由建置迴圈產生，與首頁共用 `chapter_drawing()` 和角色插畫圖集。`content/` 的 31 篇內文及照片保持原樣。

首頁精選故事封面：`img/story-field.webp`、`story-harvest.webp`、`story-table.webp` 是同系列 AI 手繪插畫，對應金山風土、挖地瓜體驗與餐桌滋味。單張 750px 橫幅 WebP，非實景或活動紀錄照片；原始照片保留於內文。PNG 母檔與替換前版本存於 `../yam51103_故事封面替換前_20261025/`。

新舊版互通（2026-10-25）：建置會把來源目錄（2015 原版）整份複製到輸出的 `original/`，略過 `.UAS` 與隱藏檔，並在複製出來的 `index.htm`、`all-2.htm`、`narrative.htm` 加上「回到 2026 重製版」的列（`remake-bar.htm`，可帶 `?to=<單元>/<頁碼>.html` 指回對應新頁）。`original/go/<單元>-<頁碼>.htm` 是 31 個深連結入口頁框，讓新版每篇的「看 2015 原版」直接開到舊版同一頁；非第一頁的單元會另外複製一份單元頁框（`go-<n>.htm`）替換內容頁（`detail`）的預設頁面。新版的主選單、頁尾與文章封面的連結由 `page_shell()` 與建置迴圈產生，樣式在 `site.css` 最後一段。`verify_build.py` 也會比對 `original/` 與乾淨重建是否完全一致。

GitHub Pages（2026-10-25）：靜態主機會對每個網頁送 `charset=utf-8` 標頭，蓋過頁面自己的 `<meta charset=big5>`，所以建置複製舊版時會把 6 個 Big5 單元頁框（及其 `go-<n>.htm` 複本）用 cp950 嚴格解碼後轉存為 UTF-8 並更新中繼資料宣告（`meta`）；其餘 45 頁原本就是 UTF-8。部署由 `.github/workflows/pages.yml` 負責：先跑 `verify_build.py` 確認提交的輸出與乾淨重建一致，再只把 `2026-remake/` 發布到 Pages。

動態效果與 UX（2026-10-25）：`site.css` 末段與 `site.js` 新增首頁主視覺進場、內頁封面進場、第一屏以外區塊的捲動顯示（`IntersectionObserver`，只對載入時不在畫面內的區塊加 `.reveal`，播放一次後移除）、標語帶跑馬燈（`templates/home.html` 以四組 `.ribbon-set` 無縫循環，滑鼠移上暫停）、章節篩選彈入、按鈕與卡片的微互動（只在 `hover: hover` 的裝置套用）、`@view-transition` 跨頁交叉淡入。頁首改為版次列隨捲動捲出畫面（`--edition-h`、`--bar-h` 由腳本量測寫入 `:root`，sticky 的 `top`、側欄與 `scroll-padding-top` 一併換算），主列固定並加陰影；手機選單改用 `grid-template-rows` 過渡並支援點外側收起。本頁導覽改為貼在頁首下方的跳段落選單（展開為浮層、點連結／點外側／Esc 收起），並隨捲動標示「現在讀到」的段落。照片燈箱支援同頁左右翻閱（按鈕、方向鍵、觸控滑動）、圖說、張數、載入指示與焦點循環。所有動態皆尊重 `prefers-reduced-motion`。
