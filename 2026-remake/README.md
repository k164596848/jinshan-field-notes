# 金山地瓜地方誌（yam51103）

「來去金山，FUN藷假」是金山高中「地瓜金正讚」小組的 2015 台灣網界博覽會作品。新版以奶油紙色、橄欖綠、地瓜紫與金黃，重新編排為地方誌。

## 瀏覽

從儲存庫根目錄啟動本機預覽伺服器：

```sh
cd 2026-remake
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000/`。

- 首頁可依「田野、餐桌、筆記」三條主題路線篩選八個單元，並搜尋章節。
- 紫藷看地圖、橘藷煮料理、黃藷寫筆記；動作版與站姿版吉祥物皆為透明 WebP。
- 內頁提供本頁目錄（有標題時顯示）、閱讀進度及可記住偏好的內文字級。
- 同單元的小節讀到篇尾會自動接續下一小節，長短篇都適用，已載入的內容可向上回看。三處導覽同步顯示目前篇名與段落；可切回單篇，也可用「單篇」開啟目前文章的網址。讀完單元最後一小節才前往下一章。
- 長篇提供底部段落選單與「接續上次閱讀」，閱讀位置暫存在目前瀏覽器分頁；網址帶有錨點時優先前往指定段落。
- 不執行 JavaScript 時，所有章節與原有頁間連結仍可使用。

## 正式來源與重建

正式來源位於儲存庫的 `src/` 資料夾，詳細說明請見 [來源說明文件](../src/README.md)。

- `templates/home.html`：首頁版型。
- `content/`：31 篇已潤飾的正式內文。
- `site.css`、`site.js`：全站樣式與互動。
- `img/`：建置需要的 WebP。

請修改來源後重建。新版建置已保留 v4 版型與正式內文，無須另外執行歷史 `copy_edits`。

## 圖片與備份

主視覺為 AI 生成的絹印風裝飾插畫，非金山實景照片。吉祥物依原美工組的角色設定進行 AI 重繪，保留紫橘黃配色、葉飾、笑臉與綠色圍裙。人物、學生及田野照片仍使用專題原始素材。

首頁主視覺提供 1000px／600px WebP；故事卡使用 600px。大型原稿與歷次修改前的備份保留在先前工作區，未包含於本儲存庫；本儲存庫的 2015 年原版保留於 `2015-original/`。

## 內頁圖文排版

全站內頁已依內容整理為導讀、章節段落、圖說相連的相簿、品種卡、料理步驟、人物與日誌等版型。照片點擊可放大，原有圖片與資料來源保留；大型比較表與分工表可橫向捲動。歷史商品、活動與飲食資料保留原專題脈絡。

## 2015 原版網站

`original/` 是建置時從 `2015-original/` 整份複製進來的 2015 原版（Namo WebEditor 頁框版），讓新舊版放在同一台主機互相連結：

- 新版每頁的主選單與頁尾都有「2015 原版」按鈕；各篇內文封面的「看 2015 原版」會直接開到對應的舊版頁面（`original/go/<單元>-<頁碼>.htm`）。
- 複製出來的舊版首頁與頁框頁上方多了一條「回到 2026 重製版」的列（`original/remake-bar.htm`）；`2015-original/` 原稿本身沒有改動。
- 這些都是建置產物，要改請改 `build_yam.py` 再重建。
